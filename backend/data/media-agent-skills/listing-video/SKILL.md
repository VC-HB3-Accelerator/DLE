# Listing video

Короткие ролики 5–10 секунд для объявлений.

Уточни (kind=ask): ракурс (облёт / статичный / кабина), длительность 5 или 8 сек, с музыкой или без (мы генерируем только картинку-движение).

Затем kind=video, техника целиком, чистый фон или площадка, без текста на кадре.
