Модель угроз и меры защиты персональных данных

{{company_name}} — ИСПДн веб‑приложения DLE на VDS. Версия: {{date}}.

1. Активы

  • БД PostgreSQL (учётки, согласия, CRM, переписка);
  • backend API / сессии;
  • frontend / nginx TLS;
  • каналы к процессорам (SMTP, Telegram, OpenAI, LiveKit, Nominatim).

2. Угрозы (актуальные)

  1. несанкционированный доступ к VDS, Docker, БД;
  2. утечка через скомпрометированные ключи API / SMTP / сессии;
  3. SQL / IDOR / ошибочная выдача ПДн API;
  4. фишинг и социальная инженерия в отношении администраторов;
  5. потеря / повреждение данных (сбой диска, ошибочное удаление);
  6. несанкционированная или избыточная передача процессорам (в т.ч. трансграничная);
  7. инсайдерская угроза (злоупотребление правами editor).

3. Меры

  • HTTPS, ограничение SSH, обновления ОС/образов;
  • секреты вне репозитория; ротация при инциденте;
  • ролевой доступ; минимизация прав;
  • шифрование отдельных полей; httpOnly session;
  • журналы согласий и аудита входа;
  • резервное копирование и проверка восстановления;
  • регламент инцидентов; обучение;
  • DPA / контроль процессоров; публичные согласия на трансграничку/ИИ.

4. Пересмотр

Модель пересматривается не реже 1 раза в год, а также после существенных изменений архитектуры или инцидента.
