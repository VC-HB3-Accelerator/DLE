# Мастер-ТЗ — KB Investor

**Статус:** STRUCTURE READY (`interested · member · faq`)  
**Аудитория:** `investor-a`  
**Цель:** корпус для ИИ-агента на пути инвестора.

## 0. Продуктовый смысл

Агент классифицирует:

1. **interested** — знакомится с тезисом, оффером, ОС;  
2. **member** — уже в контуре раунда/сделки;  
3. отвечает из оси + **faq/**.

Цифры раунда не уходят в `public-client`.

## 1. Три оси

| Ось | Вопрос инвестора |
|-----|------------------|
| `interested/` | Зачем раунд? Что за ОС? Какой оффер/сделка? |
| `member/` | Use of funds, сеть/казна, traction, swap |
| `faq/` | Короткие якоря (внутренний FAQ корпуса) |

## 2. Жёсткие ограничения

1. Цифры — только из справки хода + investor SoT.  
2. Не в `kb-wave1` / `public-client`.  
3. DEAL/SPA — по правилам аудитории.  
4. Без выдуманных пилотов/конкурентов.  
5. Аббревиатуры → глоссарий.  
6. Нет факта → вопрос + **три варианта** (`kb-wave1` MASTER §0.1).

## 3. Источники истины (старт)

`data-room/Public_Data_Room/investor-a/*`, `docs.ru/os-dle-presentation.md`, при технике — `kb-wave1`.

## 4. Порядок наполнения

1. Тезис / оффер (`interested/`).  
2. FAQ interested.  
3. Member-каноны (funds, treasury, swap…).  
4. FAQ member.
