# База знаний агента — три аудитории

ИИ-агент **классифицирует**, с кем говорит, и берёт корпус только своей аудитории.

| Корпус | Папка | Кто слушает | Оси внутри |
|--------|-------|-------------|------------|
| Клиент продукта | [`kb-wave1/`](kb-wave1/README.ru.md) | `public-client` | UI закрыт; смысл+RAG — ТЗ [`kb-wave1/00-MASTER-TZ-WAVE1B-CANON-RAG.ru.md`](kb-wave1/00-MASTER-TZ-WAVE1B-CANON-RAG.ru.md) |
| Подрядчик | [`kb-partner/`](kb-partner/README.ru.md) | `partner` | **`interested/` · `member/` · `faq/`** |
| Инвестор | [`kb-investor/`](kb-investor/README.ru.md) | `investor-a` | **`interested/` · `member/` · `faq/`** |

## Правило классификации

1. Сначала аудитория (`public-client` / `partner` / `investor-a`).  
2. Для partner/investor — этап: **интересуется** или **уже часть**.  
3. Не смешивать корпуса (цифры раунда ≠ ответы клиенту).  
4. Аббревиатуры — [`ai-agent-glossary.ru.md`](ai-agent-glossary.ru.md).

## Оси partner / investor

| Ось | Смысл |
|-----|--------|
| **interested** | Ещё изучает сотрудничество / раунд / продукт |
| **member** | Уже внутри: внедрение, процессы, контур сделки |
| **faq** | Внутренний FAQ корпуса (якоря для агента) |

Клиентский Wave 1: экраны (`settings` / `usage`). Wave 1b: канон блока + FAQ «зачем» + таблица RAG. Page в вектор не класть.
