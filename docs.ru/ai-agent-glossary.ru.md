# Глоссарий для ИИ-агента

**Для кого:** чат-агент и голосовой звонок.  
**Зачем:** канон речи. Короткие имена в корпусе оставляем для поиска; в разговоре произносим **полные формулировки** из этой таблицы.  
**Источники:** [README.ru.md](../README.ru.md), [os-dle-presentation.md](os-dle-presentation.md), [ai-assistant.md](ai-assistant.md), [blockchain-for-business.md](blockchain-for-business.md), [security.md](security.md), [service-terms](../legal.ru/service-terms.md), LICENSE, правила ассистента.

Цифры тарифов, ask раунда и долей **сюда не входят**. Их брать только из справки текущего хода и только если правила аудитории это разрешают.

---

## Как пользоваться

1. Абонент или читатель слышит **колонку «Говорить / писать»**, не буквы аббревиатуры.
2. Если в справке стоит короткое имя — раскрой его по этой таблице, смысл не меняй.
3. Названия компаний и имена собственные не «расшифровывай».
4. Не выдумывай другие расшифровки. Запрещённые подмены — в колонке «Не говорить».
5. Нет строки в глоссарии и нет формулировки в справке — скажи обычными словами или уточни, не сочиняй аббревиатуру.

## Роли ОС (доступ)

В коде четыре системные роли. Клиенту говорим понятными словами; коды оставляем для поиска в корпусе.

| В корпусе | Говорить / писать | Не говорить |
|-----------|-------------------|-------------|
| guest | неавторизованный гость; гость без входа | «просто аноним навсегда» как единственный смысл |
| user | авторизованный гость (вход есть, без порога читателя/редактора) | путать с «пользователь = редактор» |
| readonly | читатель; в UI также «Админ (только чтение)» | «readonly» вслух без пояснения |
| editor | редактор; в UI также «Админ (редактор)» | что любой вошедший — редактор |
| public-client (ярлык знаний) | публичные знания для клиента компании | произносить ярлык человеку |

Пороги токенов и вход определяют, **кем становится** человек. Матрица чата (текст/файлы/звонок) настраивается отдельно. Страница «Роли и доступ ИИ» в первой версии **показывает** права для ИИ, а не конструирует новые роли.

| пилотный узел | демонстрационный / pre-pilot контур страны (отдельный инстанс ОС) | «уже промышленный регуляторный реестр» |
| подрядчик marketplace | исполнитель заданий из казны сети — не совладелец странового ЮЛ ~75% | путать с контрибьютором узла |
| hub обновлений (HB3) | раздающий инстанс, с которого клиенты берут pack ОС; блок Gitea только при hub_url self/local | обещать настройки Gitea на каждом клиентском VDS |
| Gitea | хранилище репозиториев/pack у раздающего hub | |
| возврат 70% | программа возврата по условиям договора и условиям обслуживания — не обещать без справки | |

Срок сопровождения в каноне условий: **пять лет** обновлений, поддержки и обучения; дальше экземпляр остаётся у клиента, новые обновления — отдельно.

Старт контура: скачать шаблон и поднять рабочий контур **примерно за пятнадцать-тридцать минут**.

| LP | партнёр с ограниченной ответственностью; отличие от раунда Stage A — только из справки |
| ROFR | право первого отказа |
