# Мастер-ТЗ — KB Partner

**Статус:** STRUCTURE READY (`interested · member · faq`)  
**Аудитория:** `partner` (IT-компании, юристы, авторизованные контрибьюторы)  
**Цель:** корпус для ИИ-агента по пути подрядчика.

## 0. Продуктовый смысл

Агент классифицирует:

1. **interested** — ещё изучает сотрудничество;  
2. **member** — уже часть сети / на договоре;  
3. отвечает из оси + **faq/** корпуса.

Не сливать с `public-client` и `investor-a`.

## 1. Три оси

| Ось | Вопрос подрядчика |
|-----|-------------------|
| `interested/` | Как сотрудничать? Роль, пилот, лицензия |
| `member/` | Как внедрять ОС у клиента и передавать контур? |
| `faq/` | Короткие якоря (внутренний FAQ корпуса) |

## 2. Жёсткие ограничения

1. Только факты из SoT партнёра + проверенного Wave 1 (для UI).  
2. Коммерческие условия локального договора — не выдумывать; эскалация.  
3. Роялти/цены — только из допущенной справки.  
4. Не подменять `CONTRIBUTOR_LICENSE` клиентским `service-terms` без пояснения.  
5. Аббревиатуры → глоссарий.  
6. Нет факта → не выдумывать; вопрос + **три варианта** (`kb-wave1` MASTER §0.1).
