# Сценарий — передача контура клиенту (handoff)

**Корпус:** `partner` · `member/`  
**Статус:** DONE  
**Опора:** `00-CANON-IMPLEMENTATION-PATH` · partner SoT роль/лицензия · Wave 1 shell/access

## 1. Цель

Клиент может **сам** пользоваться контуром: чат, настройки по роли, поддержка — без ежедневной зависимости от подрядчика на каждый клик.

> «Перед сдачей: кто редактор, где секреты, что не слать в чат агенту, куда писать в поддержку.»

## 2. Чеклист передачи (без выдуманных полей)

1. Доступы: кошелёк/роли; кто `manage_settings`.  
2. Секреты: RPC, API keys, deploy key — только у уполномоченных; не в чат.  
3. Документы: политика/согласия (published / юрпакет).  
4. ИИ: какая модель/провайдер; что в RAG.  
5. Контакты: подрядчик · info@hb3-accelerator.com · Wave 1 FAQ при сбоях UI.  
6. Граница лицензии: клиент на EULA/service-terms; подрядчик на CONTRIBUTOR_LICENSE.

## 3. Не обещать

Бессрочный «мы всё ведём за вас» без договора. Обход роялти/IP. Инвесторские цифры в handoff клиенту.

## 4. Эскалация

Клиент не получает доступ редактора; спор о том, кто платит роялти; инцидент с утечкой ключей.
