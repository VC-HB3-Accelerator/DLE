## 1. Статус сейчас (*код*)

Контур **демонстрационный / пилотный**: ОС DLE live; смарт-контракты в тестовой сети где применимо; промышленная разметка регулятора **не** закреплена; ID/правила пилота ещё не согласованы в регламенте.

> «Сейчас показывают механику. Это не промышленный регуляторный контур во всех странах.»

## 2. Два контура (не смешивать)

| Головной (VC HB3 / АО → фонд *цель*) | Контрибьютор (страна) |
|-------------------------------------|------------------------|
| Сеть, регламент пилота, координация | Локальная ОС, участники, сопровождение |
| Свои БД / RAG / агенты | **Свои** (отдельный инстанс) |
| Пример: hb3-accelerator.com | РФ: **ООО «ЭРАЙТИ»** (ru.hb3-accelerator.com) |

Офер IT / доли / пакет $44k — в `00-CANON-ROLE`.

## 3. Контрибьютор в пилоте

Договор с правообладателем на территории; инициатор пилота для бизнеса и регулятора; локальная установка/сопровождение; может быть авторизованным продавцом лицензий.  
На Stage A **продажи и ops сети** — головной контур / АО Турция, не «IT сам продаёт страну за свой счёт».

Главная задача демо: довести пилот до **согласования с регулятором** → промышленный контур (*цель*).

## 4. РФ: ООО «ЭРАЙТИ» (*код*)

Собственная инсталляция DLE; подключение участников; официальный продавец лицензий в РФ по договорной модели. Это **демо** подготовки пилота, не «уже ЭПР / признание везде».

## 5. Не путать

Demo ≠ промышленный реестр. ЭРАЙТИ ≠ одна БД с HB3. Состав `team` ≠ роли этого файла. Ask Stage A — не сюда.
