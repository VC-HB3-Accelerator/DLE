# Канон — слой подрядчиков (marketplace)

**Корпус:** `partner` · ось `interested/`  
**Статус:** DONE  
**SoT:** `data-room/Public_Data_Room/partner/03-contractors-layer.ru.md`  
**Не путать с:** `00-CANON-ROLE` (IT ~75% в локальном ЮЛ)

## 1. Кто это

Специалисты и команды: настройка DLE, разработка, поддержка, обучение, документация — **исполнительный слой** экосистемы (задания), не совладелец странового узла.

> «Подрядчик marketplace берёт задания из казны. Контрибьютор узла — совладелец локального ЮЛ ~75% с пакетом открытия.»

Обычно также держатели токенов управления (*цель* / после контура фонда).

## 2. Чем не является

| Подрядчик marketplace | Контрибьютор IT-узел |
|-----------------------|---------------------|
| Оплата за задачу (из **15%** расходов казны) | Пакет страны ~$44k на открытие **не** платит |
| Не «открывает страну» | Отдельный инстанс ОС, Updates + ROFR |
| Задания из казны | Совладелец ЮЛ ~75% |

## 3. Типы заданий / оплата (*BM*)

Настройка под вид деятельности · модули · доработка · техподдержка · обучение · документация.  
Источник оплаты: **15%** казны (регулятор + юр. + IT + ops). Поступления казны в модели: лицензии DLE (**$1k / $10k**) · exits / LP (*цель*).

## 4. Стек (ориентир)

Vue 3 · Node/Express/PostgreSQL · Docker on-prem · Solidity/Hardhat · Ollama/FAISS/RAG. Код — дистрибутив DLE (Gitea / зеркала).

## 5. Как начать (*цель* / модель)

Изучить продукт → токены управления (*цель*) → профиль на hb3-accelerator.com → заявки на задания.  
Локальные ставки и наличие заданий «прямо сейчас» — не выдумывать; эскалация / SoT хода.

## 6. Не путать

С `00` ролью узла. С ask Stage A. С клиентским service-terms.
